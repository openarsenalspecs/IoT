# Rally Copilot

**Where Rally expertise meets structured AI.**

Rally Copilot is a modular, rules-based Rally course design and optimization platform for judges, instructors, trainers, clubs, and competitors. It enables intelligent course creation, validation, visualization, and optimization across multiple Rally federations using a shared spatial intelligence engine.

---

## Overview

Rally Copilot transforms Rally course design into a structured, AI-assisted workflow that blends human expertise with deterministic rules systems.

It is built as part of a broader canine sports ecosystem and is designed to scale into additional disciplines such as agility, obedience, and scent work through a shared core architecture.

---

## Core Features

### Federation-Aware Design System
- Support for multiple Rally federations (AKC, WCRL, CKC, UKC, FCI, and custom rule sets)
- Modular federation plugin architecture
- Versioned and extensible rule definitions
- Local club and custom rule support
- Class-level constraint enforcement (novice, advanced, excellent, master)

---

### Rally Space Designer
- Ring dimension configuration
- Entry and exit gate placement
- Judge table and visibility positioning
- Restricted zone definition
- Spectator boundary layout
- Spatial constraint validation
- Automatic ring optimization suggestions

---

### Station Layout Engine
- Station positioning and rotation control
- Sequence validation and enforcement
- Directional flow management
- Station spacing validation
- Numbering and ordering system
- Automated course generation (novice → advanced → master)
- Themed and training course generation
- Station legality verification per federation

---

### AI Copilot Layer
- Natural language course editing
- Voice and text-based interaction
- Context-aware course modification
- Rule-constrained AI transformations
- Example commands:
  - “Reduce congestion in the back corner.”
  - “Make this course easier for beginners.”
  - “Replace station 7 with a left turn exercise.”
  - “Improve flow and readability.”
